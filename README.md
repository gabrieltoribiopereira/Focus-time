# Focus Time

A simple focus timer for the terminal with a weekly goal.

## Run

```bash
python3 main.py
```

## Use

- **Arrow keys + Enter** to move in the menu, **q** to quit.
- **Start timer**: set the time and start. Press **q** to stop and keep what you did.
- **Goal**: change your weekly goal (in hours).
- **History**: see your week, past weeks and last sessions.

The progress bar resets every Monday. Your data is saved in `config.json`.
